**Text+ 2.0** adds 3D, patterns, paths, live data and two more animators — and shows fewer rows than 1.1.

**New**
- **A tidier interface**: 29 rows by default instead of 52. Outline, Shadow, Glow, 3D and Path each start with one switch row; animators add their properties with *+ Property*.
- **Looks**: Neon, Sticker, Comic, LED Sign, News Bar, Chrome 3D and more — one click, everything stays editable.
- **3D**: tilt the finished text in space, or extrude it with a rounded bevel, side colour and light.
- **Fill patterns** (stripes, halftone, checker, noise, LED dots) and alternating colours per character, word or line.
- **Text on a path**: arc, ring or wave, with a seamless offset.
- **Live data**: `{osc:/address}`, `{bpm}`, `{slide}`, `{weekday}` in any text; countdowns to a date; CSV row templates.
- **Four animators** with skew, blur, thickness, spacing and a range; Bounce and Elastic eases; Slides by word, shuffle, out-then-in transitions.
- **Text+ Fill**: an effect that draws text over a clip, fills the letters with it or cuts them out.

Compositions from 1.x open with the matching settings — please check them before a show. Full list: [CHANGELOG](https://github.com/floriandobler/text-plus/blob/main/CHANGELOG.md).

**Install (macOS)**
1. Unzip and copy `TextPlus.bundle` and `TextPlusFill.bundle` to `~/Documents/Resolume Arena/Extra Effects` (or Resolume Avenue), replacing an older version.
2. Remove the download quarantine once: `xattr -dr com.apple.quarantine ~/Documents/"Resolume Arena"/"Extra Effects"/TextPlus*.bundle`
3. Restart Resolume — **Text+** is listed under *Sources*, **Text+ Fill** under *Effects*.

Universal binary (Apple Silicon + Intel), macOS 11 or later.

**Windows (not yet tested in Resolume)**: `TextPlus-2.0.0-Windows.zip` contains `TextPlus.dll` and `TextPlusFill.dll` for Resolume 7 (x64). They build and pass the automated tests in a software OpenGL renderer, but have not been run in Resolume on Windows yet — feedback welcome in the issues.
