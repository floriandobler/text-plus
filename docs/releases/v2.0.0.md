**Text+ 2.0** makes the panel short and the look rich: looks in one click, an effect stack with bevel, extrude and contours, characters in 3D, text on paths, live data from OSC and the web — and **Text+ FX**, the same engine as an effect on any clip.

**New**
- **A clearer panel**: 22 rows when you start instead of 52. Effect slots and *+ Property* show only what you use; rows read "Offset X" instead of "A1 Offset X".
- **Looks**: Neon, Chrome, Retro 3D, Comic, Glass, Contours, Long Shadow and more — sized to your text.
- **Effect stack**: several outlines, glows and shadows; bevel (smooth, chisel, chrome), extrude, contours, roughen; weight; radial, stripe and halftone fills.
- **3D**: characters flip, swing and fly in from the depth; text on an arc, circle, wave or a spinning ring.
- **Live data**: `{bpm}`, `{slide}`, `{weekday}` … in any text; OSC variables (`{/score/home}`); JSON and CSV from a URL or a file; countdowns that turn red.
- **Animation**: a third animator, blur, tracking, skew and weight as properties, bounce and elastic easing, new presets.
- **Text+ FX**: text over the video, the video inside the text, or the text cut out of the video.

Compositions from 1.1 open with the same look (the old outline, shadow and glow settings become effect slots). Please check them before a show. Full list: [CHANGELOG](https://github.com/floriandobler/text-plus/blob/main/CHANGELOG.md).

**Install (macOS)**
1. Unzip and copy `TextPlus.bundle` and `TextPlusFX.bundle` to `~/Documents/Resolume Arena/Extra Effects` (or Resolume Avenue), replacing an older version.
2. Remove the download quarantine once: `xattr -dr com.apple.quarantine ~/Documents/"Resolume Arena"/"Extra Effects"/TextPlus*.bundle`
3. Restart Resolume — **Text+** is listed under *Sources*, **Text+ FX** under *Effects*.

Universal binary (Apple Silicon + Intel), macOS 11 or later.

**Windows (not yet tested in Resolume)**: `TextPlus-2.0.0-Windows.zip` contains `TextPlus.dll` and `TextPlusFX.dll` for Resolume 7 (x64). They build and pass the automated tests in a software OpenGL renderer, but have not been run in Resolume on Windows yet — feedback welcome in the issues.
