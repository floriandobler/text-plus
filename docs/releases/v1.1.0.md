**Text+ 1.1** brings plates, clocks, tickers and new animation tools — and a first Windows build.

**New**
- **Plates** behind the block or every line (radius, slant, border, melting line plates) — animate them separately: a plate wipes open, then the text follows (*Lower Third In / Out* presets).
- **Source & Display**: text from the input fields, a file or a **clock / countdown / stopwatch / counter** (`Doors open in {timer}`); shown static, as **slides**, as a **ticker** or as a **roll**.
- **Animators**: *Sequence In/Out* with *Hold*, *Wipe* in five directions, *Scramble* (decode and glitch effects), *Target* text / plate / both, *Replay Stagger*.
- **Inner glow** and **inner shadow**; *Case* Tt / TT / tt.
- **Font fallback** for missing characters (CoreText / DirectWrite) and built-in monochrome emoji with outlines and glow.

Compositions from 1.0 open with the matching settings. Full list: [CHANGELOG](https://github.com/floriandobler/text-plus/blob/main/CHANGELOG.md).

**Install (macOS)**
1. Unzip and copy `TextPlus.bundle` to `~/Documents/Resolume Arena/Extra Effects` (or Resolume Avenue), replacing an older version.
2. Remove the download quarantine once: `xattr -dr com.apple.quarantine ~/Documents/"Resolume Arena"/"Extra Effects"/TextPlus.bundle`
3. Restart Resolume — **Text+** is listed under *Sources*.

Universal binary (Apple Silicon + Intel), macOS 11 or later.

**Windows (not yet tested in Resolume)**: `TextPlus-1.1.0-Windows.zip` contains `TextPlus.dll` for Resolume 7 (x64). It builds and passes the automated tests in a software OpenGL renderer, but has not been run in Resolume on Windows yet — feedback welcome in the issues.
