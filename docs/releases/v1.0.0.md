First public release of **Text+**, a text source for Resolume Arena and Avenue 7 built on signed distance fields.

**Highlights**
- Outlines grow outward only and never eat into the letters; neighbouring outlines merge into one contour.
- Two outline bands, shadow, glow, gradients and hollow text — crisp at any size.
- *Line 2* and *Line 3+* styles (weight or font, size, colour, tracking, spacing) for lower thirds.
- Slides from typed lines, text files or CSV; a BPM-sync-friendly *Slide* slider with *Next / Previous*.
- Two stackable per-character animators driven by *Progress* (BPM sync, timeline, MIDI, OSC), with presets.
- Any installed font or a font file, HarfBuzz shaping, kerning and ligatures.

**Install**
1. Unzip and copy `TextPlus.bundle` to `~/Documents/Resolume Arena/Extra Effects` (or Resolume Avenue).
2. Remove the download quarantine once: `xattr -dr com.apple.quarantine ~/Documents/"Resolume Arena"/"Extra Effects"/TextPlus.bundle`
3. Restart Resolume — **Text+** is listed under *Sources*.

Universal binary (Apple Silicon + Intel), macOS 11 or later. Windows is not available yet.
